# GoodChat 基础聊天模板

这是可直接导入的最小完整静态项目，包含真实官方聊天核心，无需构建。

1. 在导入窗口复制提示词，下载基础模板 ZIP。
2. 打开支持文件编辑的 AI 工具，上传 ZIP，粘贴提示词并描述想要的效果。
3. 要求 AI 阅读 SKILL.md，完成后返回完整、带新版本号的 ZIP。
4. 回到 GoodChat 上传 ZIP，填写名称并校验导入。每次导入创建独立模板，不覆盖旧作品。
5. 预览并测试文字、图片、附件、选项、表单、引用和留言。满意后发布并绑定接入链接；导入本身不会自动替换线上页面。
6. 不满意时将最新 ZIP 交给 AI 继续修改，每轮递增 version，再上传测试。

index.html 为布局，static/style.css 为可编辑样式。static/goodchat 下两个脚本及 goodchat-contract.json 是固定核心，禁止修改。template.json.version 是作品版本，sdk_version 是核心版本，两者含义不同。

本地直接打开可看到官方预览内容，预览不创建真实会话、不上传文件。真实功能必须从 GoodChat 授权咨询入口测试。消息类型和校验由固定核心处理，AI 不需要重新实现。
