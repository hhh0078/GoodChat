# 邮件与通知体系方案及开发顺序

## 目标与边界

用户于2026-11-18确认直接实施。保留现有认证和聊天逻辑，复用Go、PostgreSQL、SMTP与Ant Design，不增加外部队列或AI邮件生成框架。系统及2个基础坐席免费，AI按实际Token计费，邮件不得误导为免费模型调用。仅向相关成员和已验证通知地址发送；不把访客邮箱当营销名单。

## 场景与规则

- 安全：注册、登录、重置密码、接受邀请、所有者移交验证码；密码修改成功、所有者/管理员权限变更，关键安全通知即时且不可关闭。邮箱变更仅在真正提供对应业务功能时接入。
- 邀请与欢迎：成员及平台开通邀请支持九语言品牌模板；注册和加入成功发送一次引导。没有可靠新设备识别前不做推测性登录告警。
- 账务：AI低余额和严重不足阈值可配置，仅跨阈值通知；首次调用受余额/日预算阻断时即时提醒，按状态周期去重。人工确认充值入账和套餐开通才通知，申请不等于支付。付费到期提前7/3/1天及到期时通知，续费后取消旧提醒；永久免费版不发到期邮件。
- 客服：保留现有离线留言队列，逐步共享模板和投递记录；转人工超时且仍待处理时提醒；相同AI故障合并提醒，租户只看到可操作说明，平台可查看安全故障分类。
- 运营：欢迎、周报、接入引导、更新公告通过订阅控制；摘要默认关闭，不对现有用户回填群发。产品更新由平台明确发布触发。

## 模板、语言与时区

模板有主题、正文、按钮说明及受限变量；统一银白钴蓝HTML和纯文本。平台支持九语言预览、编辑、发布、回滚，固定业务变量不能改验证码期限、金额或目标域名。敏感认证正文、验证码、原始邀请凭证不进入投递日志。

九语言：zh-CN、en、zh-TW、ja、ko、es、pt-BR、fr、de。主动验证码使用当前已确认/URL明确的请求语言；后台通知使用收件人已保存语言、企业默认、英语兜底。后台无法重新获取电脑偏好，使用用户已确认并保存的IANA时区；时间显示包含日期、时间和时区。邮件按钮携带lang/timezone，遵循现有URL优先且不再确认规则。

安全、调用受阻等紧急通知即时。一般提醒遵守个人静默时间；按收件人本地时间发送摘要和日期提醒，正确处理跨午夜及夏令时，储存与比较使用UTC。延迟任务发送前复查业务状态、权限和订阅，不发送已经处理、续费、充值恢复后的过期提醒。

## 可靠性与权限

业务通知与业务提交同事务持久化，工作器事务外调用SMTP。按事件、收件人、通知阶段唯一去重。受理、确定失败、结果不确定分别记录；暂时失败有次数上限和退避，永久失败停止，SMTP最终确认丢失及中断不盲目重发。验证码继续短时同步发送，避免排队后过期。

租户资源按认证上下文与RLS隔离；平台模板、全局记录及测试发信仅平台管理员可用，测试只能发本人已验证邮箱且限流。租户配置收件人限制为本租户有效成员，不提供任意发信接口。通知历史不包含聊天正文、客户联系方式、附件或验证码。运营退订不影响必要安全邮件。平台监控队列积压、失败、未知状态和抑制记录；供应商回执接入前不能把SMTP accepted标为收件箱送达。

## 开发顺序

1. 完成本文件；创建通知迁移与统一模板渲染（HTML+纯文本），复用现有SMTP传输。
2. 实现通知事件、领取/租约、重试、去重、个人偏好及静默时区调度；平台模板发布/回滚与记录，租户通知配置和历史。
3. 接入账号欢迎、密码安全、邀请/权限、AI余额/受阻/充值、订阅开通及到期；保留旧入口兼容。
4. 接入待处理转人工、离线留言统一品牌、AI故障聚合；可选摘要及订阅、平台明确发布更新。
5. 补齐九语言词典与邮件模板、UI，执行数据库隔离集成、认证/计费/聊天回归及浏览器检查。
6. 中文提交，合并并推送main、删除功能分支；跟进既有自动发布、健康检查与真实SMTP发送，并记录验收边界。

## 验收标准

- 模板九语言不缺变量，HTML转义及按钮目标受控，不泄露密钥与验证码；旧验证码原子消费/限流与邀请规则保持。
- 真实隔离PostgreSQL验证事务回滚、并发领取/去重、租约过期、暂时/永久/未知结果、权限/RLS、充值与续费取消待发提醒。
- 时区覆盖UTC、Asia/Shanghai、America/New_York及跨午夜静默时间/夏令时；显式URL偏好和保存偏好都正确。
- 前后端测试、类型/格式/i18n检查与生产构建通过；平台、租户、工作台真实浏览器检查，桌面与手机可用。
- 线上仅用明确标记隔离测试资源；真实业务邮件仅发用户授权邮箱1224299352@qq.com。记录SMTP受理结果，不把本地SMTP替身或HTTP成功当真实收件。没有其他邮箱收件访问权限时如实记录Gmail/163/Outlook入箱尚未实测。
- 不修改其他项目、不读取或打印私有配置密钥，验收后撤销临时测试数据和会话，完成后发指定完成邮件。

## 实施与验收记录

### 已实现

- 24类系统邮件，完整覆盖九语言。平台入口为“邮件与通知”：SMTP私有加密配置、模板预览/版本发布/回滚、投递监控、本人测试和九语言订阅公告；租户与客服可管理本人订阅、静默时间和历史，企业规则仅管理员可见。
- 041迁移建立通知设置、模板版本、幂等队列与尝试记录；042迁移用账本同事务事件表触发账务提醒，无历史流水回填。已发布模板不可覆盖；按租户、收件人、场景和业务事件去重。
- 两个后台执行器；SMTP调用不持有数据库事务。确定临时失败有限退避；永久失败抑制；受理结果不确定及租约中断转未知状态，禁止盲目重发。使用数据库时间认领即时任务，发送前复查权限、余额、套餐与转人工状态。
- 安全邮件与验证码保留既有限流、有效期和原子消费。敏感正文不入日志。运营邮件支持签名退订及邮件客户端一键POST；打开GET链接不会直接退订。
- 复用已配置SMTP，支持运行时加密保存与上一版备份；旧环境配置继续可用。离线留言继续使用原队列并共享模板及传输，新设地址必须为有效成员，已启用旧地址兼容保留。
