# 聊天窗口与模板 ZIP 工作流验收

日期：2026-11-23（北京时间）。

## 实现结果

- 悬浮窗只保留蓝色品牌栏，品牌、连接小点、文字留言、三个统一 18px SVG 窗口按钮集中展示。聊天内部不再重复白色品牌栏或独立接待状态行；咨询结束后同一位置切换为评价入口。
- 默认聊天与七行业模板使用紧凑嵌入模式。渲染时添加布局标记和展示规则，原始包、固定 SDK 与已发布版本不原地覆盖；普通独立页面保留品牌设计。
- 导入窗口只有一个上传按钮，提供四步使用说明、复制提示词、下载基础 ZIP、查看提示词。基础 ZIP 根目录含页面、样式、两个固定核心脚本、合约、SKILL.md、README.md、PROMPT.md 和 template.json。
- 作品 version 与 SDK version 分开；每轮要求递增三段版本、交付完整版本 ZIP、保留上一版。服务端导入仍校验官方核心摘要，每次导入创建新模板，用户预览后再发布绑定。
- Markdown 说明文件按 UTF-8 纯文本接收和提供，保留解压预算、路径、固定脚本与资源引用校验。
- 修复受控访客翻译兼容逻辑覆盖显式参数的问题，附件名、客服名等不再显示原始占位符。

## 三轮实际 AI 编辑

把下载包与其中同一份提示词交给独立 AI 执行文件编辑，连续产出完整 ZIP：

| 作品版本 | 实际修改 | 保护文件 |
| --- | --- | --- |
| 1.0.1 | 银白钴蓝紧凑咨询台 | 三个核心/合约文件 SHA256 不变 |
| 1.0.2 | 320px 小屏适配、声明式快捷文字入口 | SHA256 不变 |
| 1.0.3 | 自然墨绿、本地原生说明弹窗 | SHA256 不变 |

每轮均经过真实认证的模板导入接口、数据库保存、发布和接入链接绑定，再从实际访客页面使用官方 SDK。不是只验证预览替身或模型输出 JSON。产物及完整浏览器证据保存在本机忽略目录 `.local/compact-chat/`；其中运行身份与 Cookie 不提交。

## 已通过验证

- 浏览器实际复制提示词、下载 ZIP；上传入口数量与隐藏状态、四步说明、手机和桌面导入窗口无横向溢出。
- 三个版本逐一导入、发布、发送真实文字；第二版快捷文字发送与第三版本地弹窗正常。
- 三个版本逐一验证：表单必填为空不能保存、填写后保存为真实消息；选项点击产生真实文字；图片上传与授权预览；文件上传及下载入口；引用保存、本人消息撤回；320px 小屏发送入口可见。
- 七行业模板（金融、电商、教育、医疗、房产、企业、电竞）分别检查桌面 1440×900 与嵌入 360×600，均无横向溢出、发送入口可见；嵌入无重复品牌/接待行，核心消息及附件菜单正常。此组行业视觉检查使用官方纯本地预览，真实业务另由上述三轮验证覆盖。
- 默认与装修悬浮窗均真实发送、打开官方留言表单；统一图标、放大/还原/收起和手机布局正常。
- 最终源码再次真实导入并发布第三版，核对 `下载 attachment.txt` 的插值；结束咨询后蓝栏评价按钮可打开官方评价表单。
- 前端 146 项测试全部通过；九语 4138 条目录和插值覆盖通过；网页与桌面 TypeScript 检查通过。
- Go chat、decoration、localization 测试通过；chat 与 decoration 使用现有专用 PostgreSQL 测试库的集成测试通过，随机 schema 已回收，未使用生产客户数据。

## 边界

浏览器验收使用本机隔离 Chrome。没有将本地行业预览、构建通过或分支推送当作生产验收；发布后的公网检查单独记录。不改变历史已发布包，不替用户自动发布第三方 AI 修改包。外部 AI 每轮结果仍须经平台严格校验及实际预览。
