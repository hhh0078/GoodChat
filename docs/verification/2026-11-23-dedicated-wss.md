# 专用WebSocket域名

本部署运行配置 `SUPPORT_REALTIME_URL=wss://goodchat.wss.ai.58it.cn`。网页HTTP请求和领取票据继续使用当前网页域名，WebSocket连接统一采用票据接口返回的 `websocket_url`，不经普通CDN。该配置为运行期配置，独立海外部署应填写连接同一后端/数据库的当地消息域名。

`SUPPORT_PUBLIC_ORIGINS` 继续配置允许的网页来源。消息服务仅接受主网址和明确允许的网页来源，精确校验协议、主机及端口，拒绝陌生网页且不消耗其票据；原生无Origin客户端仍须通过一次性票据认证。票据有效期30秒，只能使用一次。生产端点只允许WSS，拒绝明文、URL凭据、路径和参数注入。

旧字段 `url` 保持原有相对路径，未配置专用端点的部署保持同源行为。新网页与原生客户端源码优先读取 `websocket_url`，兼容旧服务器。原生握手单独使用不含CookieJar的HTTP客户端，不向消息服务传递账号Cookie或Authorization。已安装的旧桌面二进制需要升级到重新构建的版本才能识别新字段；本次不重发桌面安装包。

宝塔现有站点只把 `/ws/v1` 转发到应用网关，保留升级头、真实来源与可信边缘头；其他业务路径返回404。握手路径关闭访问日志，避免记录短期票据。证书和DNS沿用用户已配置状态。专用消息域名不加入网页来源列表，不生成其官网地图。

## 验证范围

- 前端测试覆盖专用端点、旧相对路径、HTTP开发地址、明文降级、凭据和非法路径。
- Go配置测试覆盖端点及来源列表校验；真实隔离PostgreSQL与HTTP/WebSocket测试覆盖客服、访客、ready帧、非法Origin拒绝及票据不可重复使用。
- 原生客户端测试覆盖新旧服务器协议，并通过两个独立HTTP服务检查消息服务不会收到账号Cookie或Authorization。
- 修改发布前，生产主站领取真实访客票据，通过专用域名完成101握手、接收ready，重复使用返回401。验收会话已正常结束。
- 发布后，主站 `goodchat.58it.cn` 与备用站 `goodchat.ai.58it.cn` 实际票据均返回专用端点；两者握手101并收到ready，非法Origin返回403且不消耗票据，重复使用返回401。独立Playwright浏览器直接打开真实聊天页面，两个网页的所有消息连接均采用专用域名，并收到真实服务端event帧；本轮会话已正常结束。
- 后端Go测试、146项前端测试、九语4126条校验、前端构建通过；独立PostgreSQL客服/访客测试及新旧同源模式回归通过，原生客户端新旧协议和凭据边界测试通过。

生产首先验收的功能镜像为 `goodchat:7001472c0097`，后续主分支的 `2280d97` 仅补充未配置专用端点时的旧同源兼容。生产私有环境已配置专用WSS，无需调整DNS、证书或CDN。
