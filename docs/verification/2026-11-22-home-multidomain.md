# 首屏演示与多域名

首页左侧逐字呈现标题，右侧固定高度的对话窗口连续追加记录，底部模拟输入再发送。演示覆盖知识库、选项、必填/选填表单、提交结果、文件、语音、视频、图片和转人工。选项与表单可本地操作，数据不提交到客服数据库；上下翻阅时暂停自动跟随，回到底部恢复。历史最多保留60个步骤，场景结束直接继续下一段。

打字机和Three.js粒子场景参考用户指定的 [MotionLab文字实验](https://motionlab.uanx.online/lab?cat=text) 和 [粒子系统](https://motionlab.uanx.online/lab?cat=advanced)，使用已有Three.js依赖独立实现。旧双环组件保留，首页引用已注释。粒子限制数量、像素比和30FPS；离屏、隐藏标签或减少动态效果时停绘，WebGL不可用时回退静态点阵。标题完整文字在服务端HTML中保留。

`frontend/public/examples` 为虚构售后演示素材：TXT说明、macOS Tingting语音以及Canvas绘制的短视频，均不代表真实订单或客服承诺。原有耳机示例图片继续复用。音视频由访客点击播放，不自动发声。

## 运行期域名

- `SUPPORT_PUBLIC_URL`：本部署主网址，后台定时任务、搜索推送和没有网页请求上下文的通知使用此地址。海外独立部署必须改为当地站点网址。
- `SUPPORT_PUBLIC_ORIGINS`：本部署额外允许的网址，英文逗号分隔，例如 `https://goodchat.ai.58it.cn`。主网址自动加入允许列表。配置后需重新创建应用容器。
- 同域部署保持 `SUPPORT_CODE_ORIGIN` 与主网址相同；访问别名时装修渲染链接及CSP自动跟随别名。现有独立代码来源的版本子域隔离规则仍保留。
- 浏览器API、WebSocket、分享链接和嵌入脚本使用当前网页来源。服务端SEO、文章JSON-LD、robots、动态地图、邀请邮件、装修预览及文章管理展示链接采用网关验证的当前来源。
- 网关只接受允许列表内的Host，清除伪造的转发/内部来源头，后端只信任携带内部令牌的本机网关。未知Host回退主网址。不得将Next或后端端口直接开放公网。
- 第三方友链、客户填写的外链/图片地址和历史已发送内容不改写。静态前端构建的 `NEXT_PUBLIC_SITE_URL` 只作为无请求时的兼容回退。

地图按域名分别原子生成 `.well-known/sitemap-<hostname>.xml`，正式入口 `/sitemap.xml` 和已提交的兼容入口都返回对应站点目录。主站旧文件副本保留，失败不覆盖有效地图。新站点自定义Nginx配置代理到现有网关，转发Host并保留WebSocket升级和可信边缘头；证书不在本次修改范围。

### 旧域名CDN限制

当前 `goodchat.58it.cn` DNS指向阿里云普通CDN（Tengine响应），新别名直接指向源站。旧域名WebSocket握手返回426，正文明确表示回源缺少Upgrade头；新别名同一应用与相同反代配置返回101。CDN控制台显示该域名业务类型为“图片小文件”，创建于2026-11-22 01:03。

[阿里云官方说明](https://help.aliyun.com/zh/cdn/the-websocket-object-cannot-be-accessed-after-cdn-is-used)明确普通CDN不支持WebSocket，需要支持该协议的加速产品。未擅自替换用户刚配置的DNS/CDN或开通新计费产品。现有聊天每4秒同步持久事件，生产授权事件HTTP读取已验证可用；旧域名的WebSocket限制仍需网络层解决，不宣称全链路WebSocket通过。临时需要完整实时连接可使用已验收的新域名。

本轮显式创建的验收会话已通过各自访客身份结束；浏览器自动打开客服产生的本轮独立会话也在收尾时关闭，保留历史供核对。未向AI发送客户问题、未修改机器人知识或真实客户会话。
