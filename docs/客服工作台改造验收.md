## 网页消息故障验证

以下为真实浏览器、真实应用与持久数据库之间的故障注入，内容均明确标记“演示数据”。没有用假服务响应代替消息保存。

1. **客服页面断网**：浏览器立即显示连接恢复中；通过独立访客身份在服务端保存消息，联网后自动补齐，页面仅一条。
2. **实际服务重启**：重建后重启唯一GoodChat应用容器，原客服页面检测断开后自动重连，已有消息保留且不重复。
3. **已保存但HTTP确认丢失**：真实发送并取得服务端200后，仅向浏览器丢弃HTTP响应，刻意让WS先到；没有重复失败行。刷新后该消息仍仅一条，已确认暂存清空。
4. **请求未提交与刷新恢复**：在网络层阻断消息请求，浏览器保留完整待确认内容；刷新后仍使用同一消息编号，人工重试成功后只出现一条，暂存清空。
5. **生命周期冻结请求47秒**：通过Chrome生命周期命令请求冻结客服页面，期间分三次真实保存访客消息；恢复后3条均补齐，数量分别为1。该测试没有独立采样证明JavaScript全程暂停；后续未读复检发现自动化环境仍可能执行页面任务，因此不把命令成功等同于完整冻结。

浏览器恢复与服务端测试共同验证心跳超时、无Pong、身份撤销、旧连接回调隔离、补拉中再次到达的唤醒和签名游标重置。连接诊断提供安全连接编号及请求编号，可与服务器日志关联，不输出票据、登录凭证或聊天正文。

## 视觉与交互复检修复

- 统计曲线中线显示真实数值，不再把1.5四舍五入为2；手机按容器宽度重算SVG坐标，刻度保持实际可读字号。
- 快捷回复双击直接发送时保留未发送草稿，只有明确“插入”才追加话术。
- 备注在临时断网或503时保留已加载历史和分页，失权才清缓存。
- 保留旧内部附件备注的授权下载入口，转出或撤权后立即拒绝访问。
- 修复Next.js非特权运行用户的图片缓存目录权限，实际图片优化请求返回200。

本机截图、检查JSON和私有验收脚本存于`.local/evidence/workspace-reliability/`；凭证状态文件不提交。Playwright临时目录已排除Git。

## 交付边界

当前结论为本机容器、真实PostgreSQL与Chromium浏览器验证。生命周期命令测试不等于真实笔记本合盖或长期后台；尚未执行真机合盖、浏览器长期资源回收、Safari录音及生产网络/负载验收。不能承诺网页永不掉线。

待确认发送采用同标签会话存储，覆盖原生页面和装修可信父层；关闭标签或清除站点存储仍可能移除尚未提交消息，已经入库的消息由服务端保留。装修页面未进行整套重新发布验收，发送暂存与恢复提示在可信父层共用实现，不把装修UI改造或SDK存在称为真实模型、生产或设备验收。

演示咨询验收后结束，演示接入链接停用，个人演示话术删除；保留标明演示数据的历史用于复查，恢复验收前接待状态和音量。
