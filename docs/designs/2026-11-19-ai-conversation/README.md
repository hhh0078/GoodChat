# AI 客服连续对话卡片

用户否定了带步骤栏和播放控件的流程播放器，明确要求先设计图片，再按图实现连续聊天记录。

- `reference.png`：使用内置 ImageGen 生成的聊天视觉稿，提示词见 `prompt.txt`。
- `frontend/public/images/ai-demo-headphones.png`：同一流程生成的模拟咨询附件，提示词见 `photo-prompt.txt`。不是真实客户上传资料。
- 实现：`frontend/src/components/public-ai-demo.tsx` 与 `frontend/src/styles/public-ai-demo.css`。

保留白色界面、钴蓝品牌标志、访客右侧浅蓝气泡、AI 左侧浅灰气泡和简短知识来源。用项目现有矢量品牌母版替代图稿中的概念字母图标。桌面窗口最高 560px、宽度最高 1120px；手机最高 480px，并受当前可视高度约束。

消息逐条追加，场景自动衔接，旧消息保留在内部滚动区域，不用独立帧覆盖。没有步骤、暂停、上一条、下一条或场景切换按钮。向上阅读时不自动拉到底部；为控制长时间运行的 DOM 数量，仅回收八段对话以前的记录。减少动态偏好下展示一段完整静态对话。
