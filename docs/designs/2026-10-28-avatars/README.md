# 平台默认头像

共50张独立头像，使用内置`image_gen.imagegen`分别生成，共50次调用。人物均为虚构形象；没有使用拼图裁切或远程头像服务。

| 编号 | 分类 | 数量 |
| --- | --- | --- |
| default-01 至 default-20 | 职业人物，包含西装客服、顾问与不同年龄及外观 | 20 |
| default-21 至 default-40 | 卡通人物，包含多种绘画风格 | 20 |
| default-41 至 default-50 | 萌趣插画、动物与机器人 | 10 |

`prompts.json`保存每张独立提示词，`manifest.json`保存分类、中文名称、生产文件与工具原图文件名的对应关系；不包含私有本地路径。原图由生成工具保留，项目内仅提交生产衍生PNG。

生产文件位于`frontend/public/images/avatars/default-01.png`至`default-50.png`。通过与租户上传相同的Go图片处理流程规范化尺寸与编码，不改变人物或画面内容：

```sh
cd backend
go run ./cmd/avatar-assets ../frontend/public/images/avatars
```

当前50张均为256×256 PNG，50个独立SHA，总计4,409,160字节，最大单张105,712字节。最长边与单张体积限制由`chat.NormalizeAvatar`统一维护。

最终完整应用中逐张HTTP读取均为200；浏览器图库的全部内置图片与演示上传图片均实际加载。通过画廊及职业、卡通、萌趣样本复检头像裁切与缩略图可读性。详情见[头像与未读卡片验收](../../头像与未读卡片验收.md)。
