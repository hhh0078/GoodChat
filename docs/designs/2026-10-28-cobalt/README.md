## 当前视觉规范

界面以银白内容层、浅灰蓝工作画布和清楚的墨色文字承载工作内容。钴蓝用于主操作、选中导航、小范围图标与强调线；材质反光和微光主要留在官网视觉及界面边缘，日常表格、消息和表单保持不透明、可读。禁止蓝紫渐变、大面积深色背景和无业务用途的装饰图。

| 令牌           | 当前值    | 用途                     |
| -------------- | --------- | ------------------------ |
| `--brand`      | `#1455ff` | 主操作与选中状态         |
| `--brand-soft` | `#eaf0ff` | 小面积选中底色与品牌浅底 |
| `--ink`        | `#111a2c` | 标题与正文               |
| `--muted`      | `#5e6b83` | 辅助文字                 |
| `--paper`      | `#f4f7fc` | 工作画布                 |
| `--line`       | `#dce5f3` | 银蓝细边框与分隔线       |

前端继续使用 Next.js、React、TypeScript、Ant Design 与 Ant Design Icons。字体使用系统中文无衬线；管理页主标题 32px、节标题约 20px、正文 14–16px、辅助信息 12–13px，手机主标题收至 24–28px。采用 4/8px 节奏、8px 控件圆角、12px 面板圆角和克制的同色阴影。管理导航统一为 240px，客服工作台为 72px 紧凑导航；图稿间不一致的侧栏宽度不逐张复制。

同一操作区保留清楚的主要动作，其他操作使用次级按钮或链接；加载、空数据、失败、无权限和禁用状态必须可辨识。平台品牌更新不覆盖租户草稿、已发布装修、品牌素材和自定义 CSS，也不改变成功、警告和错误的语义。

## 真实数据与演示标识

官网产品示意统一显示“产品界面示意 · 非真实业务资料”，示例人物和消息只用于说明产品。AI 指页面设计草稿与预览发布，不将示意文字扩展为自动 AI 客服承诺；原生客户端和后续渠道不作为当前已交付能力宣传。

登录后的概览、聊天记录、统计、套餐与平台运营使用真实 API，保留现有权限和租户边界。请求失败展示错误及恢复入口，不把失败结果填成零或虚构免费套餐。价格、有效期、坐席用量和升级状态以实际配置及订阅为准。

模板作品库只陈列真实可见模板，缩略视图来自租户结构或现有素材；不能为贴合源图补造六张行业模板、假照片、选中状态或可用状态。租户原有绿色头像、页面主题等内容可以保留。平台表格不填入接口未返回的有效期、收入或增长数据。测试租户、测试消息及其截图属于测试记录，不称为真实经营数据。

## 后台响应式范围

统一规范要求覆盖 360、390、768、1024、1440px 宽度，并对较宽桌面布局继续适配。源图是桌面方向，窄屏按工作流程重排，不按比例缩小整张界面。

- 管理端在 768px 及以下使用抽屉导航；标题操作可换行，长标识省略并保留完整说明，表格在自身区域横向滚动。
- 概览在 1000px 及以下改为单列主面板，手机指标为两列；指南在窄栏采用图标、文字两列及下一行按钮，避免动作挤压。
- 模板库由桌面三列，在 1150px 及以下调整为两列，768px 及以下为一列；编辑器在 1150px 及以下纵向排列，运营设置在窄屏切换标签布局。
- 客服工作台在宽屏保留列表、对话与客户资料的工作分区；手机切换咨询列表与对话，客户资料以抽屉查看，不将桌面三栏强行压缩。
- 表单、弹层、代码区域与长 JSON 保留内部滚动或换行；按钮和图标仍需可访问名称、可见焦点及足够点击区域。
