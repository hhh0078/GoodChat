## 设计体系

使用者是正在处理咨询的客服和管理接待流程的小团队负责人。核心领域包括咨询入口、接待队列、对话、客户档案、接待范围、品牌页面、服务记录。

视觉从白色服务台、灰色工作台面、墨色文字、绿色接待状态、淡米色内部便笺中取色。主签名是“入口—接待—客户资料”的连续结构，体现在官网产品示意、工作台分栏、后台接待准备、链接与分配管理、客户记录中。

拒绝统一图标窄栏套用于所有后台、无边界灰绿平铺、大量空白与等权文本。管理页使用 216px 分组文字导航；接待页使用 72px 紧凑导航。中性画布 `#F5F6F8`、白色内容层、文字 `#22282D`、主绿 `#167558`。面板 12px 圆角，控件 8px 圆角，细边框与同体系轻阴影。字号采用 12/14/18/28 的后台层级，官网主标题为独立展示层。4/8px 间距体系，动态数字使用等宽数字。

UI UX Pro Max 的首次推荐为玻璃效果和蓝橙配色，不符合本项目；已按规范收窄检索并采用其功能性网格、层级、对比、交互和响应式要求，配色以用户要求为准。Next.js 检索中的 Server Actions 建议不适用于现有 Go API 架构，未采纳。
