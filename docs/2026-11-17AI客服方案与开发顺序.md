# AI 客服方案与开发顺序

## 已确认范围

2026-11-17 用户确认：采用 Go Eino，不使用向量或嵌入模型。先补齐文档再开发，覆盖知识库、租户媒体库、AI 话术、每客服一个机器人、平台统一模型和四项 Token 定价、费用账本。测试通过后合并推送 main。保持现有装修 AI、人工接待、关键词回复及九语言/时区逻辑兼容。

## 产品及权限

- 平台管理员维护客服 AI 接口地址、API Key、模型 ID、成本输入/输出价格、售卖输入/输出价格、调用上限；密钥仅服务端加密保存。价格有版本快照，成本只对平台可见。
- 租户拥有多个小篇幅纯文本知识库。保存正文后，平台模型自动生成使用场景描述；异步生成失败可以重试，旧发布版本继续使用，新正文和新描述同时生效。保存冲突不能覆盖更新版本。
- 每次模型请求提供当前机器人勾选的全部知识库目录及描述、话术目录及描述。模型按需通过 read_knowledge_bases 读取允许的正文；描述不替代正文。目录、正文、调用轮数均有硬上限。
- 同租户成员可浏览已启用的 AI 话术，创建自己的话术，只维护自己的；管理员维护公共话术并可停用。使用描述必填，一条话术由有序文字/图片/视频/音频块组成。机器人只允许使用明确勾选的话术。
- 每租户一个媒体库，可上传、预览、搜索、按类型过滤及查看引用；素材由上传成员维护。聊天私有附件保持原会话权限；团队素材不能因此暴露全部聊天附件。删除采用停用，已发送内容继续可读。
- 话术编辑器在光标位置插入上传或已有素材，底层使用稳定 ID。知识库可插入话术引用，但引用不会扩大机器人授权范围。
- 每个租户成员一个机器人，包含名称、服务提示词、关闭/辅助/自动模式、知识库与话术绑定、语言、接待时段、离线开关、单次输出/每日预算、连续自动回复上限、转人工规则。辅助模式由人工确认发送。
- 人工优先及租户指定默认 AI 接待入口可配置；默认机器人必须仍属于该入口的业务组和候选池，不能覆盖指定给其他客服的咨询。同一会话只有一个当前控制者。人工消息、接管、转接、关闭或新访客消息使旧任务失效。AI 消息不再次触发自动化，不计作人工首响。
- 现有关键词自动回复优先，单条访客消息只发生一次自动回复。AI 只能提出回复动作，由后端再次检查会话、版本、租户、绑定和预算后持久化发送。

## Eino 与工具协议

使用 Eino ChatModel、消息及工具绑定能力实现有界工具循环，不另建多代理平台。原生工具调用不支持、用量缺失或格式错误时进入明确失败/待核对状态，不把 JSON 直接发给访客。

- read_knowledge_bases：参数只含允许的知识库 ID，后端从任务租户及机器人绑定过滤已发布版本。
- submit_reply：参数包含有序 items，每项为 text 或 script(id, version)。工具只生成待提交计划；统一提交器执行授权、幂等与接待状态检查，避免模型直接产生不可回滚副作用。
- request_handoff：请求人工接管；实际分配成功后才承诺已接通，否则保留排队/留言状态。

供应商地址仅平台配置并校验 HTTP 协议、重定向及访问边界。知识库和访客消息属于不可信资料，不授予文件系统、任意网络或数据库工具。

## 存储与计费

沿用 PostgreSQL、现有附件存储和消息事件机制。新增模型配置/价格版本、知识库草稿与发布快照、媒体素材引用、AI 话术版本、机器人绑定、会话控制、持久化 AI 任务/调用尝试、余额与用量账本。所有租户表启用租户隔离并为表和字段添加中文 COMMENT。

首版人民币统一计价，界面每百万 Token；后台以整数微元计算，费率高精度存储。供应商实际 input/output usage 分别乘成本和售价；输入含系统提示词、目录、知识正文和历史。调用前预占预算，成功按实际值结算；未知结果保留待核对，禁止无限重试。正常辅助生成及知识描述生成也计量，系统竞态取消不重复向租户收费；供应商成本另行记录。任务唯一键防重复扣款，人工充值有流水及幂等键。

租户可设置总额度、机器人每日预算；每日按租户业务时区重置。个人时区只影响显示，数据库时间统一存储。平台可看成本/收入，租户成员只看授权的售价/用量。九语言覆盖新增页面、错误和状态；机器人回复语言跟随访客或固定配置，与客服 UI 语言独立。

## 开发顺序

1. 文档与边界：完成本文并接入现有开发文档。
2. 数据基础：迁移、模型配置加密、价格与钱包账本、权限与额度测试。
3. 内容资源：知识保存/描述任务/发布，媒体上传及授权，AI 话术版本与组合内容。
4. Eino 运行：工具协议、用量解析、预算预占结算、持久化任务及重启恢复。
5. 聊天集成：访客消息触发、关键词互斥、辅助草稿、自动发送、接管/恢复及默认机器人。
6. 管理界面：平台 AI 配置/账单/充值，租户知识库/媒体/话术/机器人/费用，工作台入口及会话控制。
7. 验证交付：Go 单元/数据库集成、前端类型/格式/九语言、真实浏览器和生产构建；记录真实供应商测试与模拟回归各自范围，合并推送 main。

## 必须验证

- 租户互相隔离，成员只能修改自己的资源，模型不能读取未绑定资源。
- 描述生成失败、旧版本发布、并发编辑、禁用/删除与正在运行任务的竞态。
- 图片/视频/音频上传与真实访客播放，历史消息引用保留，私有附件不泄露。
- 工具非法参数/超量/未知 ID、循环上限、提示词注入边界、无知识时转人工。
- 真实消息触发、连续消息合并、关键词互斥、人工抢先/接管/关闭、重启及重复任务。
- 四项价格、价格变更快照、余额不足、并发预占、整数精度、重复结算、缺失用量和超时待核对。
- 九语言和业务/个人时区、租户离线默认策略与人工恢复。

验收证据写入开发记录；构建、模拟接口、真实供应商、线上部署分别记录，不混称已完成。

## 2026-11-18 补充确认

- 统一兼容接口使用 https://goodhr.58it.cn/api/ai-compatible/v1/chat/completions，模型 qwen3.8-flash。密钥仅保存在私有配置及服务端加密版本中，文档和代码不保存真实密钥。
- 人民币每百万Token：成本输入0.1元、成本输出0.3元；售卖输入0.3元、售卖输出0.6元。后台对应微元费率为100000、300000、300000、600000。
- 用户要求访客图片输入也计费。自动模式收到图片同样创建任务；受控读取当前会话未撤回的图片，去除元数据并缩放后通过Eino多模态协议发送。按供应商实际输入Token统一核算，不把Base64长度当Token，不额外按张收费；重复携带历史图片按每次实际调用计量。平台模型需启用图片识别并通过真实连接测试。


## 操作顺序与首版边界

1. 平台管理 → 客服AI与计费：保存模型、四项价格及图片能力，点击测试连接；对租户充值。模型连接测试由平台承担供应商实际费用，不扣租户余额。
2. 租户或客服 → AI客服：先上传媒体；创建知识库并等待使用描述发布；创建AI话术，明确写出具体使用条件，再按光标插入素材。建议每库聚焦一个业务主题，正文不超过16KB。
3. 机器人设置：勾选允许读取的知识库和话术，设置名称、头像、回复语言、业务时段、每日额度及连续回复数；先调试，再选择辅助或自动模式。辅助生成已计费，确认发送不再次计费；可编辑文字后人工发送。
4. 管理员可选择AI优先和默认机器人。未配置机器人、没有余额或未启用模型时不会偷偷开启AI；原人工和关键词路径继续生效。人工接管、转接、关闭或发送公开消息暂停AI，可在会话内恢复，恢复仅处理下一条访客消息。
5. 用量与账单显示真实输入/输出、图像输入、实扣费用和状态；平台可核对未知调用。每次模型调用费用按微元向上取整、任务汇总实扣；无结果、迟到或系统竞态取消不扣租户，平台保留供应商成本。格式不合格的一次协议修复由平台承担，禁止无限重试。

首版识别访客文字及图片，最近12条公开历史最多携带3张访客图片；图片去元数据、最长边1024，单张最多20MP/10MB。图片原件仍按既有附件权限保存。访客音频、视频和其他文件不做语音转写/视频分析，会明确转人工；AI发送图片、视频、语音通过已授权话术完成。首版不含向量、联网搜索、通用代码工具或模型生成媒体。

普通成员可查看团队已启用的资源、维护自己的资源；管理员可停用资源但不借个人接口改写别人。删除为停用，历史发送附件保留。业务时段与日预算使用租户业务时区，显示时间使用用户偏好时区；语言与时区继续遵循URL优先、否则电脑检测并确认的现有规则。
