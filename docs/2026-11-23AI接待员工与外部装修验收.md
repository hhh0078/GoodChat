# AI接待员工与外部装修验收

日期：2026-11-23。

## 行为变更

- 每个新旧租户固定一个默认AI员工，无独立登录、不占人工席位，暂不提供删除。可编辑显示名称、受控头像、服务说明及启停；继续复用现有机器人、模型、知识库与话术。显式选择AI的入口自动由AI接待，管理员的入口授权独立于配置者的人工坐席及组资格；旧默认机器人策略仍保留原权限边界。
- 转人工后暂停AI，按创建入口的自动分配、领取或指定客服配置继续处理，不再被AI接回。AI接待计入接待中；在线且等待人工的咨询才计入当前排队。离线旧咨询保留历史，不占自动分配队列。工作台、概览、入口统计统一处理。
- 主站CDN拦截PATCH，浏览器改用POST携带受限方法覆盖，服务端仍调用原PATCH路由和鉴权。其他方法及非API路径不能覆盖。真实界面切换示忙、正常均保存成功。
- 请求失败统一为确认弹窗，保留原说明、请求编号和表单输入；遮罩及Esc不能关闭，同一故障的轮询及并发反馈去重。连接健康状态、未确认附件等持续业务状态保留相应状态说明和重试入口。
- 移除后台在线AI代码生成页面、入口、接口、提示词及工作器。旧任务停止，历史模板、不可变发布、使用账本保留。外部AI装修向导复用正式提示词复制、ZIP下载和导入校验；菜单按日常工作、接入运营、团队设置、统计折叠。
- 知识补充邮件包含真实问题、原因和待办入口，按待办去重，发送前取消已处理提醒。兼容旧自定义邮件模板并对HTML转义。

2. 前端143项测试、九语言4173条文案覆盖与ICU校验、TypeScript、桌面端类型检查及Next生产构建通过。
3. 使用已授权真实供应商qwen3.8-flash在随机schema中验证：知识读取与回答、图片理解与用量、图片/视频文件/语音话术发送、显式转人工、未知问题合并、补充发布后再次回答、表单与选项发送及填写后不重发；另验证英语、法语回答。费率及账本为隔离验算，不作为生产收费金额报告。视频容器夹具只验证工具与消息落库，不宣称真实可播放视频验收。
4. 实际浏览器复制提示词并下载ZIP，新建可见Codex任务 `01a20498-de73-7b01-bd10-138aebed84f4`，使用同一提示词及附件，返回银白钴蓝 `1.0.1` ZIP。交付件经正式严格导入、发布和链接绑定；浏览器验证文字、图片、文件、必填/选填表单保存后的消息、选项、引用、撤回、附件名称、悬浮窗及结束后的评价入口。
5. 九语言分别检查1440桌面与390手机的AI成员、折叠菜单及装修向导；另检查德语接入、模板、工作台。模板检查320/390/430手机、768平板、844×390横屏和1440桌面，无横向溢出且发送可见；400高视口中聚焦输入并实际发送。此为浏览器视口与输入测试，不宣称手机真机软键盘已验收。下载包SKILL要求交付者继续执行PC、移动端、横屏、软键盘、安全区与富消息验收。
6. 确认弹窗在真实浏览器中注入明确标识的隔离400错误：原始说明及请求编号可见，确认前不消失，确认后保留输入并能真实重新保存。另经真实状态接口验证POST覆盖PATCH成功，未用模拟响应宣称后端状态保存。
