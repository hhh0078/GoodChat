# AI客服开发与验收

2026-11-18，开发顺序见《2026-11-17AI客服方案与开发顺序》。

## 已交付

- Eino原生工具循环：描述目录→按需读取知识→文字/授权话术→后端重新授权发送，最多四次调用，无向量。
- 多知识库及保存时AI描述、异步发布、版本冲突检查及历史恢复；媒体库真实上传/预览/搜索/类型过滤/自己的资源维护，历史消息保留。
- AI话术必填描述，光标处插入图片/视频/语音并保留前后文字，可调整顺序；机器人绑定白名单，禁止模型生成任意媒体URL。
- 每客服一个机器人，名称/头像/辅助或自动/回复语言/业务时段/每日额度/连续自动消息上限；默认AI接待与真实转人工，关键词优先、人工接管失效旧任务。
- 平台加密密钥、不可变价格版本、钱包预占/实扣/幂等充值/平台成本及未知用量核对；租户RLS、成员资源权限、会话最新消息及控制版本重查。
- 访客图片是真实多模态输入，按接口实际输入Token计价；账单展示图片输入次数，重复携带按实际调用累计，不是额外按张收费。
- 新页面与错误覆盖九语言，遵循既有URL/电脑确认语言时区；个人显示时区不改变租户业务时间。

## 正式配置

接口 https://goodhr.58it.cn/api/ai-compatible/v1/chat/completions，模型 qwen3.8-flash。人民币每百万Token成本输入0.1/输出0.3元，售价输入0.3/输出0.6元。真实密钥不入库到Git、不进入响应或日志，使用服务端AES-GCM加密保存。新机器人默认关闭，需要明确配置并有余额。

## 运行边界

访客音频/视频输入暂不识别或转写，明确转人工；可通过话术发送音视频。图片最大20MP/10MB、缩放最长边1024、最近12条公开历史最多3图。首版只支持人民币，充值为平台人工入账，不接支付网关。仍需供应商支持原生工具和真实usage；超时或缺失usage进入平台核对。人工审核与充值策略由实际运营决定。
