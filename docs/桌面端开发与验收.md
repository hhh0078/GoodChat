# 桌面端开发与验收

日期：2026-11-16。

用户确认使用完整桌面工作台、系统WebView及原生消息模块；同一份代码支持Mac和Windows。打包可指定版本及默认服务器，每次启动显示服务器选择，允许修改和恢复打包默认值。

## 已实现

- `desktop/` 独立Go模块，Wails v3.1.0；复用现有React、Ant Design客服界面。
- 原生服务器配置与系统凭证库，账号、服务器和租户隔离；选择新服务器不会转发旧待发消息。
- 原生HTTP、WebSocket、心跳超时、退避重连、持久事件恢复与SQLite发送队列。
- 前台既有提醒与后台原生提醒交接、按成员音量播放固定提示音、系统通知授权和托盘运行。
- Mac ARM64、Intel及通用DMG；Windows x64、ARM64免安装ZIP打包入口；版本同时写入界面和系统元数据。
- 手动触发的GitHub Actions双系统构建流程，参数与本机脚本一致。

具体打包命令、存储位置及发布边界见 [桌面端说明](../desktop/README.md)。以下初次验证记录保留历史范围，后续版本见追加记录。

- `go vet ./...`：通过。
- 原网页Next.js生产构建：通过。
- 桌面与现有网页TypeScript检查：通过；原有122项及新增2项服务器草稿隔离测试通过，共124项。
- 已实际生成Mac通用DMG（Apple silicon / Intel，约24.1 MB）和Windows x64 ZIP（约12.0 MB）；准确大小与SHA256以 `desktop/dist/` 产物及伴随JSON记录为准。
- Mac实际运行本地打包程序，已观察到版本、记住服务器选择、地址限制、恢复打包默认值与登录界面。用明确标注“本机界面夹具（非业务验收）”的本地空数据检查了完整工作台布局；修复默认地址按钮的表单同步，并补齐复用工作台所需的共享样式。

## 仍需真实设备验收

Windows实际安装/运行、WebView2缺失时的引导、Windows凭据管理器与通知；Intel Mac实际运行；真实客服账号和访客双向消息、附件、语音、通知声音、睡眠唤醒、切换网络、服务端重启以及长时间后台运行。开发测试包尚无正式Windows代码签名，Mac无Developer ID公证；不能称为公开发行版或全部业务已验收。
