# 工作台与运营验收

日期：2026年10月29日。验收环境为本项目本机 Docker 应用、PostgreSQL、Redis，访问地址 `http://127.0.0.1:13000`。使用独立、明确标记的演示租户；未操作其他项目，未给其他用户发送测试邀请邮件。

## 交付范围

- 工作台快捷区仅展示添加入口与小号换行标题；个人在前，公共在后，只有两组都有内容才显示横线。按当前客服成功发送次数排序，重试同一消息编号不重复计数。支持文字、图片、语音、文件、视频和选项，双击保留原输入草稿。
- 两端输入区使用胶囊与图片／文件／视频添加菜单，访客发送为圆形图标，客服发送为长胶囊。暂隐藏录音入口，保留语音消息播放。两端及标准装修页面使用真实输入位置到真实消息位置的发送动画。访客点击消息后显示引用与撤回。
- 客户表合并头像、姓名、电话、资料值标签与时间，按所选对象搜索；右侧客户档案隐藏访问页面，聊天记录展示对应客服。客户表在中等窗口使用局部横向滚动，避免标签逐字竖排。
- 日常、租户管理、平台管理菜单分开；所有有效成员都有自己的头像选择和上传入口。新增成员统计、团队在线、接入管理今日数据、平台资源监控和人工压测基线管理。
- 租户重复提醒默认10秒，五种提示音均为1秒。仅当前接待人领取真实未读或尚未查看的新咨询，已读、转出、结束后停止。多标签原子领取同一周期提醒；没有可用提醒通道的标签不抢占。个人音量与静音继续生效，访客新收到人工客服消息也有声音提示。
- 复访优先级为指定客服、窗口内历史客服、正常流程。指定客服离线阻止访问；历史客服离线回退正常分配。默认0分钟永久优先，大于0按服务端最后公开消息时间计算，无消息按创建时间；心跳与已读不延长窗口。跨客服历史默认共享，关闭后统一限制消息、事件、引用、附件和导出，管理员保留审计权限。
- 按服务空间和入口保存访客凭证、会话编号、资料和链接参数。新参数覆盖旧参数，保留0和false；服务端验证身份、路由和有效窗口，浏览器时间与缓存编号不构成授权。

## 边界

这些结论只代表本地容器与浏览器验收，不代表生产部署或真实并发压测。当前容量页无真实业务压测基线时显示待校准，不推算虚构的可承载人数；CPU和内存明确标记实际可见的容器或进程范围。

浏览器Worker无法保证系统睡眠、合盖、冻结或丢弃标签页期间持续运行；本轮验证了浏览器离线恢复和持久消息补拉，尚未执行物理合盖、休眠及所有浏览器后台策略实测。网页关闭后的提醒需另接Web Push或客户端。现有实时服务仍为单实例，横向扩容前需增加共享事件分发。维护入口和参考资料见《实时连接与消息恢复》。

标准组件装修与新代码初稿已同步交互能力；已有租户自行发布的代码模板保持原样，需要由租户更新模板后采用新界面。
