# 认证页与官网视觉检查

## 当前检查范围

用户反馈登录页左侧过素。以本次线上截图和实际页面为依据检查登录、注册、找回密码、邀请、首页、功能、价格、客户端下载、使用场景与接入帮助；不涉及登录后的私有业务数据，不执行注册、发验证码或修改密码。

## 发现与修正

1. 四个认证页面共用的左栏以浅灰通用对话为主，正文、边框对比偏弱，功能说明没有突出AI客服。复用现有官网知识库回复示意，加入钴蓝标题栏、知识标签、明确的人工接管说明与免费/AI计费提示；手机保留紧凑能力标签，语言入口移到顶部品牌旁，避免覆盖长注册表单；长登录标签允许换行。
2. 价格页只在导语中解释AI计费，增加独立说明区域，修正手机长语言注册按钮的裁字。金额、坐席和实际权益继续读取后端，不硬编码模型报价或修改计费。
3. 下载页重复展开相同长更新日志，改为可键盘操作的“更新说明”折叠区，并增强平台图标层次；实际版本和下载地址仍来自公开API。
4. 首页底部仍称macOS和Windows后续接入，与当前真实公开下载列表不符，移除过期提示。首页、功能、场景页已有产品示意，保持现有结构；帮助页保留便于阅读的文档布局。

## 实现约束

沿用银白、钴蓝、现有双环素材与Ant Design，不增加依赖或第二套UI库。复用现有九语言词典，不修改语言/时区决策、认证接口、验证码发送及密码逻辑。对话明确标记为产品示意，不代表真实客户记录或实际回复承诺。
