# 用户端模板与可视化编辑

[English home](../../README.md) · [中文首页](../../README.zh-CN.md) · [English](../en/templates.md) · [官网](https://goodchat.58it.cn)

GoodChat 提供金融、电商、教育、就诊服务指引、房产、企业咨询、电竞七套响应式在线客服用户端模板。每套都是 HTML、CSS、JavaScript 和静态素材组成的文件包，用户端无需二次编译。模板负责呈现，消息收发、WebSocket 通信、附件、留言等业务动作统一调用 GoodChat 官方核心。

以下均为**本机真实浏览器截图**，使用中文界面和模拟咨询内容。页面根据已确认的设计稿实现，图片不是设计概念图。每套分别展示电脑端和手机端，点击图片可查看原始尺寸。

## 预览与使用

1. 租户所有者或管理员进入**模板管理**（`/console/templates`），点击平台或行业模板卡片预览，分别检查电脑和手机模式。
2. 点击**添加到我的模板**，创建归当前租户所有的独立副本。**复制并下载**也会先创建本租户副本，再导出文件；修改副本不会覆盖平台原稿。
3. 在**我的模板**中，通过**更多 → 编辑模板**打开静态文件点选编辑器。
4. 调整后通过**更多 → 创建页面**创建独立页面。页面拥有自己的草稿和发布历史，不覆盖模板原稿。

预览使用模拟消息，用于检查外观和控件；预览不等于发布的访客入口，也不会创建真实客户咨询。

## 点选元素编辑

在**选择编辑**模式点击预览中的元素，或从左侧元素树选择。右侧属性面板支持：

- 修改独立文字元素的文案；容器含子元素时，选择对应的内部文字节点。
- 修改 CSS 类名和当前元素的 CSS 声明。
- 修改输入提示、图片说明，上传或替换图片。
- 修改运行时聊天气泡、控件等动态元素的样式。模拟消息内容不会回写到原始 HTML。

切换**交互预览**后，可以试用控件。修改源码或属性后，点击**更新预览**校验并重新渲染当前草稿；**保存草稿**会创建新的资源包修订，线上页面仍需发布后才会更新。

## HTML、CSS、JavaScript 与图片

源码面板可编辑 HTML、CSS 和附加界面 JavaScript。**增加 HTML**用于插入本地片段，**额外 JavaScript**打开 `static/custom.js`，可编写说明弹框等界面交互。手机与电脑的响应式断点在 CSS 源文件中调整。

典型文件包结构如下：

```text
index.html
static/style.css
static/custom.js
static/…图片素材…
static/goodchat/sdk.js        # 官方保护文件
static/goodchat/chat-ui.js    # 官方保护文件
goodchat-contract.json       # 平台写入的合约
```

点击**上传图片**加入本地素材，或先选中 `<img>` 元素，再点击**上传并替换图片**。保存草稿后，图片随模板静态文件包一起保存。

编辑器根据图片类型、体积和尺寸判断是否需要压缩。合适的小图保留原内容，过大的静态图片可缩小处理；透明 PNG 保留透明，GIF 保留动画，不会静默转换成单帧。服务端继续检查真实格式和资源限制；不符合要求时会提示选择更小或受支持的图片。

## 核心业务动作使用官方 SDK

普通模板编辑器与 AI 无法覆盖官方 SDK、聊天 UI 和合约。平台校验固定脚本的引入、实际字节、版本、摘要及完整性属性。模板文件可以增加本地界面交互，业务动作则使用官方 SDK 及其声明式标识。

例如，留言按钮可以自由设置外观，同时打开既有官方留言表单：

```html
<!-- 文件作用说明：通过官方核心打开当前访客的留言表单。 -->
<button type="button" data-gc-action="leave-message">留下留言</button>
```

对应 SDK 方法是无参数的 `GoodChat.openLeaveMessage()`。可信宿主提供当前访客上下文并负责表单提交。模板不自行实现 WebSocket、身份处理、附件传输或消息接口。模板下方最底部的平台技术支持保留显示。

平台管理员可在管理配置中维护带版本的官方核心与提示词；这与租户修改普通模板文件分开，租户源码和 AI 输出不能替换受保护核心。

## ZIP 下载、离线修改与导入

**下载**导出完整 ZIP，包含入口 HTML、CSS、附加 JavaScript、图片、官方脚本和资源清单。离线调整页面与样式时，保留受保护文件原样。重新导入会创建新的私有资源包，并执行相同的合约校验，不会静默覆盖原模板或既有发布版本。

已有模板也能作为 AI 二创起点。该流程使用当前租户配置的 AI 服务，可上传参考图片，并创建独立结果。本图库的七套页面均根据已确认设计稿手工实现。

## 发布与链接绑定

创建或编辑独立页面，预览后发布版本。在咨询链接的**用户端模板**字段选择已发布页面，再选择更新方式：

| 更新方式 | 实际行为 |
| --- | --- |
| 固定已发布版本 | 入口继续使用选中的不可变发布版本。 |
| 跟随此页面之后的发布 | 入口随该页面后续发布更新。 |
| 不选择额外模板 | 继续使用 GoodChat 现有默认用户端页面。 |

保存模板草稿不等于发布页面；修改源模板也不会覆盖已经创建的独立页面。清空链接模板绑定后，该入口恢复默认用户端页面。

## 删除前检查引用

通过**更多 → 引用与删除**查看入口、页面和运行中的生成任务。停用入口也可能引用模板，需要先切换或解除绑定。执行删除时，服务端会再次检查引用。

满足删除条件后，GoodChat 同时清理模板拥有的无绑定页面及历史，回收无引用资源包文件与生成素材。仍被其他对象拥有或使用的文件会保留，删除一个私有副本不会删除其他租户的模板。
