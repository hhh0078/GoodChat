# GoodChat 功能导览 — 在线客服、客户服务与可定制用户端模板

[English](../en/features.md) · **简体中文** · [项目首页](../../README.zh-CN.md) · [官方网站](https://goodchat.58it.cn)

GoodChat 是一套支持私有化部署的多租户在线客服系统，面向需要统一处理咨询、管理客户资料并定制用户端页面的服务团队。Go 后端与 React 客服工作台将接待分配、实时聊天、回复运营、服务统计和 HTML 客服模板连接在同一个应用中。

本页介绍仓库中已实现的功能。截图来自**实际运行的中文界面，使用演示与验收数据**；英文文档不代表应用界面已完整国际化。所有截图均为压缩后的 WebP 文件，行业模板展示的是实际渲染页面，而不是设计概念图。

## 谁可以使用 GoodChat？

| 角色 | 主要工作 |
| --- | --- |
| 访客 | 打开咨询链接、与服务团队聊天、发送附件、提交留言和评价会话。 |
| 客服 | 处理分配的咨询、使用个人话术、查看客户上下文、维护接待状态。 |
| 租户所有者或管理员 | 邀请成员、配置入口与分配、管理客户和运营规则、定制模板、查看统计。 |
| 平台管理员 | 管理租户、公共模板、套餐、升级申请、平台 AI 配置和服务器监控。 |

管理角色与接待资格分别设置，管理员不必自动成为接待客服。

## 1. 实时聊天与客服工作台

客服工作台将咨询列表、消息记录和客户上下文放在一起，方便客服切换会话、查看未读动态并维护可接待或忙碌状态。会话操作包括认领、接受、拒绝、转接和关闭，执行时遵循当前接待规则。

消息支持文字、图片、文件与音频，并提供授权预览或下载。引用回复、已读状态、输入提示和限时撤回帮助双方跟进沟通。浏览器录音及播放能力取决于目标浏览器的支持情况与授权。

![GoodChat 客服工作台：咨询列表、实时聊天和客户上下文](../media/screenshots/workspace.webp)

### 网络变化后的消息恢复

消息通过 HTTP 接口持久化，使用稳定的客户端消息编号。WebSocket 负责及时通知浏览器有新动态，持久事件补拉负责恢复中断期间遗漏的更新。界面区分连接中、恢复中和已连接，不把套接字刚打开当作同步完成。

发送结果未确认时，重试继续使用原消息编号，不会在结果不明时默默生成一条新的成功消息。浏览器冻结、系统睡眠仍可能中断连接；产品提供的是重连与同步恢复流程，不承诺连接永远不断。

## 2. 客户资料与服务上下文

客户档案提供服务所需的上下文，不必额外部署销售 CRM。团队可以使用标签、标签分类、客户分类和自定义字段组织联系人，再按现有字段搜索和筛选。访问记录、内部备注和备注附件帮助后续接待延续沟通背景。

租户管理员可按需要拉黑客户。客户姓名、手机号等展示字段属于档案资料，不能代替访客会话凭证进行身份认证。

![客户资料管理：搜索、联系信息与分类](../media/screenshots/customers.webp)

## 3. 团队成员、邀请与权限

所有者和管理员可以维护成员、邀请、接待资格、业务分组和席位。邮箱验证用于注册和接受邀请，系统还提供密码登录、邮箱验证码登录、密码重置、会话管理与所有权转移。

个人服务工具归当前客服所有。团队规则由管理员维护，在客服个人视图中展示的共享规则可保持只读，避免误改整个团队的内容。

![团队成员、角色与接待资格管理](../media/screenshots/members.webp)

## 4. 咨询链接与接待分配

团队可以为不同推广渠道、业务线或服务场景创建多个咨询入口。链接支持来源信息、配置的访客字段、接待方式以及已发布用户端模板的绑定。没有额外绑定模板的链接继续使用系统内置用户端页面。

通过多个链接区分入口，可以让不同业务使用各自的接待页面，同时在同一租户工作台内处理咨询。

![新建咨询链接的空白配置对话框](../media/screenshots/access-links.webp)

### 将咨询分配给具备资格的客服

分配配置支持手动接待、轮询与持久加权轮询。业务分组和分配池定义接待范围，必备技能与可选技能进一步筛选候选客服。容量、可用性及资格检查依据当前接待状态执行，排队咨询重试时也会重新判断。

历史客服优先有助于回访客户联系到之前的服务人员，但仍要求该客服当前具备接待资格。转接、排队与关闭属于同一套会话生命周期。

![业务分组、分配池与会话分配规则](../media/screenshots/routing.webp)

## 5. 快捷回复、欢迎语与关键词规则

公共和个人快捷回复减少重复输入。富媒体话术可以包含文字、图片或可点击的咨询选项，客服既可以维护自己的内容，也可以使用团队共享资料。

![快捷回复配置对话框：已填入但未保存的示例](../media/screenshots/quick-replies.webp)

欢迎规则支持不同作用范围、服务场景和配置内容。管理员维护团队规则，客服也可以管理个人欢迎设置。规则预览用于查看显示效果，不代表已经向真实访客发送消息。

![欢迎语规则与服务场景配置](../media/screenshots/welcome-rules.webp)

关键词规则提供另一种发送已准备服务内容的方式。这是配置式规则，不是通用 AI 问答引擎。

![关键词规则配置对话框：已填入但未保存的示例](../media/screenshots/keyword-rules.webp)

## 6. 离线留言与服务评价

访客可以提交离线留言、联系资料和允许的附件。租户工作台提供留言跟进列表，方便团队继续处理。可选的邮件提醒带有投递记录与重试入口，启用前需要正确配置 SMTP。

![离线留言内部跟进表单，已裁去联系人姓名和手机号](../media/screenshots/offline-messages.webp)

会话评价支持满意度反馈、评价时间配置和修改历史。管理员可以结合实际咨询查看反馈。

![会话满意度评价](../media/screenshots/satisfaction.webp)

## 7. 聊天记录、统计与数据导出

聊天记录页面提供已有筛选条件，帮助团队查找历史咨询。历史消息是否可见取决于当前租户、成员权限和配置的接待范围，不能仅凭提供一个会话编号获取记录。

![聊天记录搜索与筛选](../media/screenshots/conversation-history.webp)

租户报表按日期、客服和入口渠道汇总真实服务活动，提供访客量、咨询量、排队或进行中状态、消息量、等待时间和首响等指标。日期范围遵循租户配置的时区。

![客户服务统计、趋势与分类汇总](../media/screenshots/reports.webp)

成员统计和链接统计帮助管理员查看服务分布与入口表现。统计反映已经记录的业务活动，不会把模板预览中的模拟消息当作真实客户咨询。

![成员接待与服务统计](../media/screenshots/member-statistics.webp)

具备权限的管理员可以导出筛选后的 CSV 数据。较大导出通过支持取消的异步任务执行，并受进度、有效期和存储额度管理。下载时会再次检查权限；消息撤回后，如果旧结果会泄露已撤回正文，则需要重新生成相关导出。

## 8. 七套响应式用户端客服模板

用户端模板是 GoodChat 的重要组成部分。内置行业模板包含七种独立设计方向：

| 行业 | 视觉方向 |
| --- | --- |
| 金融 | 浅蓝与金色、顾问摄影和专属咨询布局。 |
| 电商 | 朱橙品牌、包裹摄影和轻快的售后沟通。 |
| 教育 | 暖纸白、墨绿、书本摄影和学习问题边注。 |
| 医疗服务 | 白青配色、诊室摄影和清楚的就诊服务说明。 |
| 房产 | 暖砂留白、编辑式衬线标题和室内空间摄影。 |
| 企业服务 | 黑白字体、混凝土空间和聚焦需求的会客布局。 |
| 电竞 | 黑曜与青柠、电竞设备摄影和深色聊天界面。 |

每套均有电脑与手机布局。模板卡片直接展示实际渲染页面，并可打开完整预览，让租户先比较风格，再创建自己的私有副本。

![七套行业用户端模板及可直接查看的页面预览](../media/screenshots/template-library.webp)

导出包由 **HTML、CSS、JavaScript 与静态资源**组成。租户可以下载修改后重新导入，不需要二次前端编译。消息、附件、历史、咨询选项、留言与评价继续由平台提供的固定脚本处理。

在[用户端模板图集与编辑流程](templates.md)中查看七个行业更大的手机和电脑截图。

## 9. 可视化编辑、源文件与受控发布

内置可视化编辑器支持在实际预览中点选元素，再修改文字、CSS 类名和样式。源码视图支持 HTML、CSS 和受控的本地 JavaScript。图片可上传或替换，程序检查格式、像素与体积，仅在必要时压缩。

额外 HTML 和本地 JavaScript 可实现该页面专属的服务说明弹框等交互。普通模板编辑中的聊天 SDK、消息界面脚本和资源包合约保持只读，将视觉定制与消息基础能力分开。

![用户端模板点选编辑器：预览、元素选择和 CSS 属性](../media/screenshots/template-editor.webp)

源文件改动保存为新的不可变资源包，租户页面修改在明确发布前保持为草稿。咨询链接可以跟随发布页面或固定到某个版本，删除前会检查引用，再回收不再使用的文件。平台模板库修订单独维护版本，保留租户已有的私有副本。

## 10. AI 辅助模板设计

管理员的 AI 助手支持参考图片、持久对话、多轮设计修改和已有模板二次创作。右侧预览使用模拟消息，方便发布前查看页面效果。

租户与平台分别维护自己的模型配置，文字/视觉模型与生图模型可以通过兼容接口独立设置。服务端校验返回的文本或文件 JSON，将生图作为受控步骤，并拒绝生成内容替换受保护聊天脚本。密钥加密保存，配置接口不返回明文。

平台管理员可通过独立的基础设置维护系统提示词和官方核心脚本版本。已有资源包继续保留原脚本快照，普通模板编辑与 AI 输出不能改写这些快照。

![管理员 AI 模板助手：新建对话与右侧空白预览状态](../media/screenshots/ai-assistant.webp)

*尚未生成模板的新设计对话。*

当前 AI 功能是**模板设计辅助**，不是自动回答访客问题的客服机器人，也不是能任意操作业务的代理。调用需要正确配置供应商、模型权限和使用额度；模型目录里可见，不代表已经拥有调用权限。

## 11. 租户设置、回调与运营控制

租户设置汇集接待策略、历史消息行为、通知偏好等服务配置。可选功能同时受角色权限和套餐权益约束。

![租户服务设置与运营控制](../media/screenshots/tenant-settings.webp)

访客进入回调可以将入口事件连接到团队自己的外部系统。回调通过异步投递执行，提供稳定事件编号、HMAC-SHA256 签名、投递记录和重试控制；接收系统应校验签名并按事件编号去重。

## 12. 平台管理与套餐

平台管理员拥有独立的租户、公共模板、套餐定义和升级申请管理视图。平台概览汇总已经记录的活动，不替代各租户自己的授权边界。

![平台租户与服务运营概览](../media/screenshots/platform-overview.webp)

套餐定义控制席位、有效期与功能权益。受保护的免费版提供两个长期有效的席位。升级申请与人工开通已经实现，该模块不处理在线支付，也不是支付网关。

![免费版套餐的席位与权益编辑侧栏](../media/screenshots/platform-plans.webp)

## 13. 服务器与接待监控

平台监控展示实测的应用或控制组资源、数据库连接池健康、实时连接数和接待容量汇总。界面会说明数据范围，不能把容器测量值当作未接入监控的整台物理宿主机容量。

![服务器资源、连接状态与手录演示容量基线](../media/screenshots/server-monitor.webp)

*图中 100 人为手录演示基线。*

容量估算需要设置测量基线，并不承诺任意部署都能承载固定数量的并发用户。

## 技术架构与交付范围

- **后端：** Go、PostgreSQL、Redis，以及持久化的消息和事件数据。
- **网页界面：** Next.js、React、TypeScript 和 Ant Design。
- **用户端定制：** 在隔离来源中渲染的 HTML/CSS/JavaScript 静态资源包。
- **部署：** GoodChat 应用镜像，单独配置 PostgreSQL 和 Redis；邮箱验证与通知需要 SMTP，AI 供应商按需配置。
- **访问控制：** 租户范围授权、业务表行级安全，以及平台、管理和客服职责划分。

当前产品形态是浏览器在线客服与客户服务 SaaS，不能从截图推断已提供原生电脑/手机客户端、社交渠道连接器或在线支付集成。目前实时推送为单实例实现，横向扩容需要共享事件分发。生产 HTTPS、域名、备份、供应商权限与目标浏览器测试属于实际部署工作。
