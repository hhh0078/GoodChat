# GoodChat Logo

以已选的“G + 对话气泡”设计为依据，统一整理成钴蓝单色矢量标志。标准色为 **#165DFF**；透明区域使用真正的Alpha通道。图形与GoodChat字标均为矢量路径，SVG不依赖查看者安装字体。

打开 [preview.html](preview.html) 可离线查看各形状；[manifest.json](manifest.json) 登记自动生成的交付文件。

| 目录 | 内容与用途 |
| --- | --- |
| `source/` | 图形SVG母版、转曲字标母版、已选设计参考PNG |
| `svg/` | 透明标准标志、反白、黑色、方形、圆角、圆形、浅底、深底、遮罩安全图标、横版与上下组合 |
| `png/` | 各形状的透明或实底PNG，按名称分组 |
| `webp/` | 128、256、512像素无损透明WebP |
| `icons/` | Windows ICO、Mac ICNS与Apple标准iconset |
| `social/` | 1200×630网站分享图 |

## 尺寸

- 单图形和图标：16、24、32、48、64、96、128、180、192、256、512、1024像素；透明钴蓝图形另含2048像素。
- 横版组合：高度32、48、64、128、256像素，宽度保持母版比例。
- 上下组合：128、256、512、1024像素。
- ICO：内含16、24、32、48、64、128、256像素。
- ICNS/iconset：包含16至1024像素的标准1倍与2倍显示资源。
- `goodchat-maskable`：实底并预留安全区，供浏览器图标遮罩使用。

## 网站中的使用

- 官网导航、页脚、登录注册、404和工作台侧栏：复用 `Brand` / `BrandMark`，展示透明图形与原生GoodChat文字。
- 官网产品示意中的平台标志：反白标志配钴蓝背景。
- 浏览器标签：SVG及32/48像素PNG；旧浏览器回退ICO。
- Apple收藏图标：180像素不透明实底PNG，由系统裁切形状。
- 浏览器清单：192/512像素普通图标及512像素遮罩安全图，不提供离线消息能力。
- Open Graph和社交分享：1200×630图，不依赖页面截图。
- 租户自定义Logo、行业模板中的商家标志和客服头像保持原有配置。

网站只复制 `frontend/public/logo/` 中的必要素材，完整交付包不进入Docker构建上下文。`desktop/icon.png` 和仓库说明中的图标也同步为新版源文件；已发布的0.1.1安装包没有重新打包，下一次客户端发布时才会包含新图标。

## 重新生成

项目已有前端依赖时，在仓库根目录运行：

```sh
node logo/export.mjs
```

脚本复用前端现有Sharp，不安装额外依赖；自动验证PNG尺寸和ICO目录，并同步网站图标。Mac上还会调用系统 `iconutil` 生成ICNS。Linux/Windows可生成SVG、PNG、WebP和ICO，保留仓库已有的ICNS。

字标已转曲，日常导出不需要字体。只有更改名称或重新整理字形时，才需要在macOS运行：

```sh
swift logo/build-wordmark.swift > logo/source/goodchat-type.svg
node logo/export.mjs
```

SVG适合继续放大或印刷排版；不要拉伸变形、添加渐变或改动气泡负空间。
